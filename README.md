# 🐍 Projeto 3 - Lógica de Programação com Python

Repositório dedicado à resolução de exercícios práticos de lógica de programação desenvolvidos em **Python**, como parte dos estudos no curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

---

## 📂 Estrutura do Projeto

O projeto contém o desenvolvimento progressivo de algoritmos e lógica, totalizando 11 questões:

* `questao_1.py` — Exercício inicial de lógica e sintaxe Python
* `questao_2.py` — Estruturas condicionais e operadores
* `questao_3.py` — Manipulação de dados e cálculos matemáticos
* `questao_4.py` — Estruturas de repetição
* `questao_5.py` — Processamento de sequências numéricas
* `questao_6.py` — Validação e tratamento de entradas do usuário
* `questao_7.py` — Contagem, classificação de dados por gênero e validação de fluxo
* `questao_8.py` — Lógica avançada de tomada de decisão
* `questao_9.py` — Agrupamento e processamento de listas
* `questao_10.py` — Automação de rotinas lógicas e relatórios simples
* `questao_11.py` — Exercício final de consolidação de lógica com Python
